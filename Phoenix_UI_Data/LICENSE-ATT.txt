class and level limits, daily/weekly flags, and English NPC and quest names) is extracted by
tools/questdata/build_questdata.py from the AllTheThings source database

Turn-in positions (the last three fields of a retail record) are computed from Blizzard's client tables
QuestPOIBlob, QuestPOIPoint and UiMapAssignment (build 12.1.5.70448, read as CSV from wago.tools). They are
game facts used as data, like the IDs Phoenix checks in tools/ids. No code from AllTheThings is included.
