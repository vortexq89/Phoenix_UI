### Core
- Core: shared foundations for every module (plan 1.19–1.29, F1, F2, F4). `PUI.Auras` builds Blizzard's CustomAuraContainer for every surface: canonical, validated aura filters; add-only groups (a removed group is capped at 0); diffed filter, cap and sort changes; flow layout; restyles wait while auras are secret; private-aura anchors as a raid-frame option, released by owner. Ledgers: `PUI.CVars` (owner-tagged, restores your prior value only while it is still ours, shared CVars released by the last owner, BigWigs-style exclusions), `PUI.Bindings` (override bindings per owner, applied out of combat, one conflict check across Phoenix modules and your Blizzard bindings) and `PUI.FrameLedger` (records parent, points, shown, alpha and scale; one owner per frame; restore on disable). `PUI.Visibility`: one "where to show" rule model (content, combat, group, spec; hide while resting, in a vehicle, skyriding, in a pet battle or mounted) with a plain-language "why hidden" reason, event-driven only while watched and coalesced to one pass per frame. Shared services: `PUI.Format` (short / grouped / plain numbers and decimals as settings; secrets formatted by the engine), `PUI.Range` (refcounted, check speed setting), `PUI.Mouse` (one cursor poll), `PUI.Glow` (C-side animation glows with a shared style/colour setting pair). `PUI.Season`: season, dungeons, timers and affixes from the live API and one M+ score colour source (Blizzard, Raider.IO when installed, or your own gradient). Own dialogs: confirm, keep-or-revert with a countdown, and a read-only copy box (no StaticPopup), plus "open this Phoenix page" chat links. `PUI.Search`: plain-text search (quoted exact, ID then prefix, all words) as a budgeted job that a new query cancels. `PUI.CastBar`: one cast bar element with a shared 13-event dispatcher (registered only while bars exist), engine-timed bars, a not-interruptible overlay driven straight from the engine, fade-out, and the single own-interrupt state with a cooldown indicator.
- Core: per-specialization and per-condition overrides (arena, battleground, raid, party, solo) for any setting marked overridable, stored inside the profile and resolved at read time (condition > spec > profile > default), never swapped in; "Editing as" sessions, promote to profile, clear, list, provenance for every row (`Schema:Source`), events only while overrides exist, protected settings applied out of combat.
- Tools: `lint.py` (implicit globals, Ticker-only timers; self-proof fixtures) runs in CI. Tests: Ledger, Visibility, Services, Season, Search, CastBar, Auras, Dialogs and Overrides suites (24 new cases).
