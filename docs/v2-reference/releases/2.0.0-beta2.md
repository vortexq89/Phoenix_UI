# Phoenix UI 2.0.0-beta2 (draft, not published)

Draft release notes built from CHANGELOG.md "Unreleased". Not a GitHub
release and not uploaded to CurseForge or Wago; publishing waits for the
in-game test pass and your go-ahead.

## Highlights
- **Every Blizzard window in the Phoenix theme.** 62 windows and surfaces keep Blizzard's own layout and features, with Phoenix scroll bars, dropdowns, checkboxes, buttons and item borders. Each window has its own switch and a gear cog for its extras (spellbook cast times, talent rings, junk overlay, have/need counts, Great Vault glow and more). Skins are chosen in the setup wizard.
- **Damage meter restyle.** Blizzard's own meter data in Phoenix's look, with header fade and docking.
- **Sentinel error reporter.** Catches every error, including other addons', grouped per addon, with copy, send, search and a full log that can auto-upload through the Companion app.
- **Minimap button bin.** Collects every addon button, including late ones and compartment entries, as a popup grid or docked bar, with search, drag order and combat hide.
- **Forever client.** Flight timer, pet happiness, an optional swing timer, an optional fishing helper, and spellbook and talent skins.
- **Plugin API v1.** Third-party modules can register settings, theme looks and timers (docs/PLUGINS.md).
- **Nameplate colour packs.** Import and export pack strings, with packs per dungeon or raid.
- **Arabic** as an optional language in settings.

## Also in this release
- Studio layout mode with movers and connectors, Edit Mode integration.
- Unit frames, raid and party frames, nameplates, action bars, cooldown manager and resource bars, with deferred items finished.
- HUD (minimap, tooltip, data bars), Chat, Vault (bags), Embers, Ascent, Quest Tracker, Reminders.
- Flow quiet mode, Raid Tools, Group Finder helpers, boss tools, PvP UI, Friends filter, Pulse, Arena, Spark and Cast History.
- Diagnostics: profiler, CPU chip, A/B window.

## Known limits
- Line-of-sight fade, Group Finder lockout filters, private-aura sounds on some content, and Friends app-only rows use workarounds (see docs/REVIEW_2026-10-27.md).
- Translations other than English are partial.
- Per-dungeon NPC colour lists come after the test phase.

## Upgrade notes
- Settings from 2.0.0-beta1 carry over. The retired Sentinel safe-mode switch is gone; modules are never turned off after errors.
