# Group Finder (PUI_V2 6.6, plan 5.16 / 15.7, mockup 08) - step 9a

Premade Groups Filter parity built Phoenix's way, plus AutoQueue's queue helper. 184 settings (most are per-category filter chips), each with Simple/Advanced views and a live preview that runs the real filter on sample rows.

Files: `Expr.lua` (filter language), `Data.lua` (result -> plain variables, activity cache, season words), `Filters.lua` (chips per category, why-hidden counts, sort), `GroupFinder.lua` (Blizzard-row decoration, tooltip section, presets, server filter, schema, conflict choice), `Panel.lua` (docked panel), `QueueHelper.lua` (role checks, sign-up helpers, role per spec, role bar, Enter button).

- **Never** rebuilds Blizzard's list or writes its result/decline tables (G14). Blizzard rows get a Phoenix line (score in the PUI.Season colour source, best key, missing roles, role fit, age, declined), role indicators in tank-healer-damage order with class bar and leader crown, row colours (new / declined / cancelled / delisted, each a colour setting) and are dimmed when the filter rejects them (dim strength is a setting).
- **Filter builder:** chips per category (dungeon, raid, delve, arena, rated BG, custom): score and PvP rating ranges, role counts min/max, members, age, item level, delve tier, my role fits, not declined, needs/has Bloodlust, has battle res, has healer, friends inside, voice, delisted, difficulty and bracket ticks, "only these" dungeon words. The chips generate a readable expression; an extra expression can be typed (and/or/not, brackets, comparisons, + - * /), validated in plain words with the position and a "did you mean". Searchable word list (`Words` button), autocomplete helper, sort spec ("mprating desc, age asc", stable).
- **Hidden-count line:** "showing X of Y - Z hidden: score 11, role full 4" (first failing chip counts); click to relax the chip hiding the most. `/pui lfg why`.
- **Phoenix panel:** docked right/left/detached, scale, density (comfortable/compact/ultra), compact view, rows; sorted matching groups (click selects in Blizzard's list, double-click signs up), applications count, your keystone (read from Ascent, which owns keystones).
- **Presets:** `/pui lfg save <name>` and `/pui lfg filter <name>` per category.
- **Also narrow Blizzard's search** (opt-in): minimum rating / needs my role through `C_LFGList.SaveAdvancedFilter`; your previous Blizzard filter is saved and restored.
- **Queue helper (AutoQueue parity):** role-check accept, sign-up auto-confirm (hold Shift to choose) and double-click sign-up are ON at first install (D-MOD-DEF2) with the taint explanation as info; one role-per-spec setting (manual / auto from spec, stands down while BigWigs sets roles / own list per spec ID); docked role bar with lock icons, collapse and first-run tip; big Enter button and countdown bar on a queue pop (never pressed for you; time from `PUI.Queue`, the shared provider; `queue.lfgSeconds` sets the dungeon invite length); optional extra sound, role print, keyword auto-invite (friends/guild only, lockdown-aware). `/pui queue on|off`.
- **Free text:** Blizzard's title, comment and sign-up note boxes cannot be written by addons; Phoenix never tries.
- **Conflicts:** Premade Groups Filter (hard choice, nothing changes until you pick); AutoQueue (soft choice for the queue helper only).

Deferred: raid boss-defeated filters and lockout matching (no search-result encounter API in the catalog), cancel-oldest-application button (`C_LFGList.CancelApplication` not in the catalog; the panel says when you are at 5), Raider.IO score/milestone variables and realm-to-region badge, plugin sort hooks, click-to-insert in the word list (it is a copy box for now), Studio mover for the detached panel, Forever gating review.
