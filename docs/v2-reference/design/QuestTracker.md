# Quest Tracker (PUI_V2 5.10) - Phase 5 core

Phoenix tracker built from C_QuestLog: watched quests grouped by sort (zone header / level / distance / type), filter (all / in progress / ready), collapsible sections remembered in `qt.collapsed`, progress colours, completion sound, click to open the quest, Ctrl-click for a Wowhead link box. Optional zone auto-track and auto accept/turn-in (Shift to read; only with at most one reward choice). Blizzard's objective tracker is hidden out of combat while on and restored when off. Distance sort refreshes on the Ticker (2 s) only while selected.

Deferred: quest-item hotkey (SecureActionButton), scenario/M+ objective mode, bonus/world quest progress bars, per-quest timers, tracker skin details.
