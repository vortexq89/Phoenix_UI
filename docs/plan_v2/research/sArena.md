# sArena_Reloaded v2.6.7

**Purpose:** arena enemy frames with 9 layouts (BlizzArena, BlizzCompact, BlizzRaid, BlizzRetail, BlizzTarget, BlizzTourney, Gladiuish, Pixelated, Xaryu), DR tracking, trinkets, racials, spec detection, cast bars, dispels, auras.
**Licence:** original sArena is MIT; the "Reloaded" fork adds an All-Rights-Reserved clause for its own additions → study only. **Altered attribution:** 40 files.
**Options:** 416 AceConfig settings. Modules: Absorbs, AuraHighlight, Auras, Clicks, CooldownFrame, Dampening, DiminishingReturns, Dispels, Fonts, ImportExport, Interrupt, Masque, ModernCastbar, PetFrames, Racials, RangeCheck, SpecFinder, TestMode, Textures, Trinkets, Widgets.
**Data shipped:** DR category lists per expansion, interrupt and dispel spell lists, trinket/racial IDs (spell IDs are facts; Phoenix builds its own list from DB2 SpellCategory/ SpellCooldowns where possible).
**Phoenix target:** Unit Frames › Boss and arena frames (arena trinket/racial/DR, spec icon, test frames) + PvP module extras. Layout presets idea → Phoenix "frame presets".
