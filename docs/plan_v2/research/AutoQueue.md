## Parity audit (22 Oct 2026)

Every feature of this addon now has one Phoenix owner page, a status and a stage in [../PARITY.md](../PARITY.md) (generated by `../data/parity_build.py`).

What AutoQueue does and what Phoenix can do (checked against its code and the 12.x API docs):
- **Role checks:** AutoQueue calls `CompleteLFGRoleCheck(true)` when the role-check pop-up shows. Our API reference lists no restriction on it (verify in game); Phoenix currently accepts with a key you press and S26 adds an opt-in automatic mode.
- **Dungeon-ready pop-up:** AutoQueue clicks a secure button from a timer. Phoenix treats entering as needing your click (Blizzard only calls AcceptProposal from the Enter button) and offers a key binding instead; in-game check.
- **Sign-up:** AutoQueue clicks Blizzard's Sign Up button from code on double-click. Phoenix's click-again / Enter sign-up is the allowed form; signing up without your input is not built.
- **Role bar:** pick tank / healer / damage before queueing — missing, S28.
